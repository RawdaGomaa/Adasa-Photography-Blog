# Adasa — React + Tailwind CSS v4

A migrated Tailwind CSS version of the original React photography blog. The original project structure and React functionality are preserved. Styling lives in Tailwind CSS utilities generated in `src/tailwind-classes.js`; a minimal `src/styles.css` contains Tailwind imports, globals and animation keyframes.

Run `npm install` and `npm run dev`.

**Visual verification is still required.** See `TAILWIND_MIGRATION.md` for migration details and limitations.
