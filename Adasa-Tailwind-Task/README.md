# Adasa Photography Blog 📸

A modern and elegant photography blog website built using React, Tailwind CSS, and Vite.

## 🌐 About The Project

Adasa is a photography blog website designed to showcase photography content through a clean, modern, and visually appealing interface.

The project focuses on responsive web design, reusable React components, and a smooth user experience.

## ✨ Technologies Used

- React.js
- JavaScript
- Tailwind CSS
- HTML5
- CSS3
- Vite

## 🚀 Getting Started

To run the project locally:

1. Clone the repository.
2. Navigate to the project folder.
3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the local URL provided by Vite.

## 🏗️ Build

To create a production build:

```bash
npm run build
```

## 📱 Responsive Design

The website is developed with responsive design principles to provide a consistent experience across different screen sizes and devices.
